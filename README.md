# SipVPN landing

Светлый лендинг SipVPN на React, TypeScript и Vite.

## Локальный запуск

```bash
npm ci
npm run dev
```

## Production-сборка

```bash
npm run build
npm run preview
```

Готовые файлы появятся в `dist/`.

## GitHub Pages

Workflow `.github/workflows/deploy-pages.yml` собирает и публикует проект при каждом push в `main`.
В настройках репозитория выберите **Settings → Pages → Source → GitHub Actions**.

Перед публичным запуском подключите форму доступа к вашей CRM или форме регистрации и подтвердите платёжные способы из FAQ.
